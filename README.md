## JupyterProject

A personal learning repository documenting my journey into Machine Learning and Data Science. Machine Learning is a branch of artificial intelligence that enables systems to learn patterns from data and make predictions or decisions without being explicitly programmed. This repo currently focuses on the foundational building blocks every ML practitioner needs: data manipulation with Pandas for handling tabular data, numerical computing with NumPy for efficient array operations, and exploratory data analysis to extract meaningful insights from raw datasets. As I progress, I plan to expand into supervised and unsupervised learning algorithms, model evaluation techniques, feature engineering, and eventually deep learning with frameworks like TensorFlow or PyTorch. The notebooks here serve as both practice exercises and a reference for anyone starting out on a similar path.
